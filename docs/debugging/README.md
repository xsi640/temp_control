# 调试指南

适用于五路温控系统（Arduino Pro Mini 5V/16MHz + 5 路 NTC + 5 路 SSR）。
建议按 **静态检查 → 5V 上电 → 传感器 → 显示/编码器 → SSR 空载 → 带载热测试** 的顺序进行，
每次只增加一项，确认无误后再进行下一步。

> **安全第一**：调试、烧录、改线时断开 220V，只保留 5V 弱电。
> 带 220V 测量必须使用额定电压足够的仪表和探头，建议由具备强电经验的人员操作。

## 1. 上电前静态检查

断开 220V 和加热器，SSR 输出侧不接负载，然后检查：

- 板子是否为 **5V / 16MHz** 版本，而不是 3.3V / 8MHz。
- 5V 与 GND 之间没有稳定短路；若万用表显示接近 0Ω，先查电源和焊接。
- OLED 的 VCC/GND 没有接反，SDA 接 A4、SCL 接 A5。
- 编码器 A/B/SW 接 D2/D3/D4，公共脚接 GND；编码器不能接 VCC 作为公共端。
- 每路 NTC 的中点接对应 ADC 引脚，NTC 另一端接 GND；上拉电阻在 VCC 与 ADC 之间。
- **通道 5 使用 A6**：A6 在 Pro Mini 板尾的内侧排针上，只能做模拟输入，不要误接到 D6 或其他数字口。
- SSR 输入正极接 D5–D9，负极接 GND；SSR 输出侧与 220V 回路按接线图连接。
- 没有锡渣、连锡、虚焊；电解电容极性正确。

断电测量 NTC 分压（至少断开一端更准确）：

| 测量点 | 25℃ 附近参考 | 异常含义 |
| ------ | ------------ | -------- |
| ADC 引脚 ↔ GND（NTC 侧） | 约 10kΩ | 0Ω：NTC 短路/连锡；开路：NTC 断线 |
| ADC 引脚 ↔ VCC（上拉侧） | 约 10kΩ | 0Ω：上拉短路；开路：上拉未接 |
| VCC ↔ GND | 不应稳定导通 | 接近 0Ω：电源短路，禁止上电 |

## 2. 分段上电

### 第一步：只接主板

只接 5V 和 GND，不接 OLED、NTC、SSR。测量：

- VCC 对 GND：**4.75–5.25V**。
- 主板电流：通常几十 mA；若明显超过 200mA，立即断电排查。
- 板载电源指示灯（如有）应点亮。

### 第二步：接 OLED 和编码器

- OLED 应点亮并显示界面；编码器旋转/按键应有反应。
- 若 OLED 不亮，先查 5V、GND、SDA/SCL 和地址，见后文。
- 若编码器无反应，先查公共脚是否接 GND、A/B 是否接 D2/D3。

### 第三步：逐路接 NTC

一次只接一路，观察串口/OLED 对应通道：

- 室温 25℃ 左右应显示接近 25℃。
- 未接 NTC 时显示 `ERR` 且该路 SSR 关闭，这是正常的故障保护。
- 五路都接好后，确认没有通道长期 `ERR`，也没有温度明显偏离室温。

### 第四步：只接 SSR 输入，不接 220V

- 用万用表测 D5–D9 对 GND：关闭时约 0V，导通时约 5V。
- 观察 SSR 输入指示灯（如有）是否随 `HEAT` 状态变化。
- 此时 SSR 输出侧不接负载，不要触碰 220V 端子。

### 第五步：最后接 220V 负载

- 确认保险丝、线径、端子绝缘和接地都符合要求。
- 先用灯泡等可观察的负载验证通断，再换加热器。
- 用钳形表测加热器电流，确认不超过 SSR 和线材额定值。
- 带 220V 时不要插拔杜邦线或触摸板子。

## 3. 串口日志

波特率 **9600，8N1**。上电首先输出：

```text
5-channel temp controller ready
SET 32.0 HY 0.8 HEAT 2 | L1 31.4 H | L2 30.9 H | L3 32.1 - | L4 ERR | L5 31.8 -
```

字段含义：

| 字段 | 含义 |
| ---- | ---- |
| `SET 32.0` | 当前设定温度（℃） |
| `HY 0.8` | 当前回差（℃） |
| `HEAT 2` | 当前正在加热的通道数（0–5） |
| `L1 31.4 H` | 通道 1 温度 31.4℃，SSR 正在导通 |
| `L2 30.9 H` | 通道 2 温度 30.9℃，SSR 正在导通 |
| `L4 ERR` | 通道 4 读数无效，SSR 已强制关闭 |

- 控制周期为 **1 秒**，所以日志大约每秒一行。
- 屏幕只在显示文本真正变化时重绘；串口在跑但屏幕暂时不闪，不代表死机。
- 打开串口时 DTR 可能复位板子，看到 `ready` 是正常现象。
- 需要时间戳时可用：

```bash
arduino-cli monitor -p COM3 -c baudrate=9600 --timestamp
```

## 4. NTC 读数校验

固件使用上拉接法，计算公式为：

```text
R_NTC = R_REF × ADC / (1023 - ADC)
1/T   = 1/T25 + ln(R_NTC / R_NTC25) / B
T(℃)  = T(K) - 273.15
```

当前参数：`R_REF = 10kΩ`、`R_NTC25 = 10kΩ`、`T25 = 25℃`、`B = 3950`。
下表按 5.00V 计算，ADC 为 10 位值（0–1023），实际会有几个字的误差：

| 温度（℃） | NTC 阻值（Ω） | ADC 参考值 | ADC 引脚电压（5.00V） |
| --------: | ------------: | ---------: | --------------------: |
| -20 | 105,385 | 934 | 4.57V |
| -10 | 58,246 | 873 | 4.27V |
| 0 | 33,621 | 788 | 3.85V |
| 10 | 20,175 | 684 | 3.34V |
| 20 | 12,535 | 569 | 2.78V |
| 25 | 10,000 | 512 | 2.50V |
| 30 | 8,037 | 456 | 2.23V |
| 32 | 7,379 | 434 | 2.12V |
| 40 | 5,301 | 354 | 1.73V |
| 45 | 4,348 | 310 | 1.52V |
| 60 | 2,486 | 204 | 1.00V |

判断方法：

- 25℃ 时 ADC 约 **512**、电压约 **2.50V**；32℃ 时 ADC 约 **434**。
- ADC 接近 **1023**（引脚接近 5V）：NTC 断路、未接或上拉把引脚拉高。
- ADC 接近 **0**（引脚接近 0V）：NTC 短路或 ADC 被短接到 GND。
- 读数偏低很多：可能用了 100kΩ NTC。100kΩ 探头配 10kΩ 上拉时 ADC 约 930，
  固件仍按 10kΩ 计算，25℃ 环境下会显示约 -19℃，而不是直接 `ERR`。
- 读数整体偏高/偏低：检查 NTC 的 B 值、25℃ 阻值和上拉电阻；B3950 与 B3435 不可混用。
- ADC 是比例测量：VCC 从 5.0V 降到 4.8V 时，绝对电压会变，但 ADC 比例基本不变，
  所以不要只用“电压不是 2.50V”判断故障。

固件判定 `ERR` 的条件：

- ADC `< 5` 或 `> 1018`；
- 计算出的 NTC 阻值 `< 50Ω`；
- 计算出的开尔文温度不在 100–500K；
- 最终温度超出 `TEMP_MIN_LIMIT`（-20℃）到 `TEMP_MAX_LIMIT`（45℃）。

因此环境低于 -20℃ 或高于 45℃ 时，所有通道都会显示 `ERR` 并停止加热。
这是软件保护逻辑，不是传感器一定坏了；如果应用场景超出该范围，需要同时调整
`TEMP_MIN_LIMIT` / `TEMP_MAX_LIMIT` 和 NTC/负载的适用范围。

## 5. 温控逻辑验证

### 回差控制

以默认 `SET 32.0`、`HY 0.8` 为例：

- 温度低于 **31.2℃**（SET - HY）时，SSR 导通；
- 温度高于 **32.8℃**（SET + HY）时，SSR 关闭；
- 在 31.2–32.8℃ 之间保持当前状态，避免在目标点反复通断。

所以温度 31.5℃ 时显示 `----` 是正常的，不代表加热器坏了。

### 滤波与响应

- 每个控制周期采样一次，8 点滑动平均，`FILTER_SAMPLES = 8`。
- 温度阶跃后，显示值大约需要 **8 秒**才能完全跟上；调试时不要期待瞬间变化。
- 出现 `ERR` 后滤波缓冲会重新播种；恢复有效读数时会立即用当前值填满缓冲，避免旧温度拉偏。

### 故障与保护

- 拔掉任意一路 NTC，约 1 秒内该路应变为 `ERR`，SSR 关闭。
- 重新接好 NTC，下一周期应恢复显示；若仍 `ERR`，检查接线和 ADC 电压。
- 软件超温/低温保护会在读数越界时强制关闭对应通道，但它**不能替代独立硬件保护**。
  长期无人值守时，建议增加机械温控器、热熔断器或独立超温保护器。

### SSR 输出验证

- 万用表测 D5–D9 对 GND：`HEAT` 时约 5V，`----` 时约 0V。
- 若 GPIO 电压正确但 SSR 输出不导通：查 SSR 输入极性、输入电压范围、负载和保险丝。
- 若 GPIO 为 0V 但 SSR 仍导通：立即断开 220V，可能是 SSR 击穿/选型错误/输出侧短路。
- 带 220V 时优先用钳形表测加热器电流；不要用普通表笔直接跨接强电端子。

## 6. 常见故障排查

### 6.1 五路全部 ERR

优先查公共部分：

- 5V 是否正常，GND 是否共地；
- NTC 的 GND 是否真正接到板子 GND；
- 是否只接了信号线、没有接 NTC 另一端；
- 是否误把 5V 接到了 ADC 引脚（会接近 1023）；
- 板子是否选错为 3.3V/8MHz 或供电不足。

### 6.2 单路 ERR

- 该路 NTC 断线/短路/虚焊；
- 中点接错 ADC 引脚；
- 上拉电阻未接或阻值错误；
- 通道 5 的 A6 没有接线：A6 在板尾内侧，不在 A0–A3 旁边；
- NTC 阻值低于 50Ω（近乎短路）会被判为 `ERR`；
- 温度超出 -20–45℃ 也会显示 `ERR`。

用万用表测该 ADC 引脚电压：接近 5V 查断路，接近 0V 查短路，约 2.5V 但温度不对则查探头参数。

### 6.3 温度偏高或偏低

- NTC 不是 10kΩ B3950，或 B 值与固件不符；
- 上拉电阻不是 10kΩ / 精度太差；
- 探头位置靠近加热器、靠近柜壁或没有插入被测区域；
- 探头线太长且与强电并行，受到干扰；
- 固件没有每通道校准参数，五路共用同一组 NTC 参数；需要高精度时选同批次探头和 1% 电阻。

可以先用冰水混合物（0℃）和稳定室温做两点核对。若所有通道都同方向偏差，优先怀疑 NTC 参数；
若只有一路偏差，优先怀疑该路探头、电阻或接线。

### 6.4 温度跳动 / 读数不稳

- NTC 线松动、端子氧化或虚焊；
- 探头线与 220V/SSR 输出线并行；
- 5V 电源纹波大，或 SSR 通断导致地弹；
- 编码器/SSR 干扰进入模拟输入。

处理顺序：

1. 缩短 NTC 线，远离强电，使用双绞线或屏蔽线；
2. 在 ADC 引脚与 GND 之间加 **100nF** 电容（靠近板子）；
3. 5V 电源加 **470–1000µF** 电解电容和 0.1µF 陶瓷电容；
4. 强弱电分开走线，单点接地；
5. 必要时把 `ADC_SAMPLES` 从 5 调到 10，或 `FILTER_SAMPLES` 从 8 调到 16。
   增大滤波会占用更多 RAM/延长响应，修改后看编译输出的剩余 RAM。

### 6.5 该加热但不加热

按顺序检查：

1. 当前温度是否已经高于 `SET - HY`？例如 SET 32.0、HY 0.8 时，31.5℃ 不加热是正常的。
2. 串口该路是 `H` 还是 `-`？`ERR` 会强制关闭。
3. D5–D9 对 GND 是否有 5V？没有则查引脚定义、焊接和板子型号。
4. SSR 输入正负极是否接反？输入电压是否在 3–32V DC 范围？
5. SSR 输出侧是否接在正确的回路中？保险丝/断路器是否闭合？
6. 加热器是否损坏？用灯泡或已知负载替换测试。
7. 5V 电源是否被 SSR 输入拉低？5 路同时导通时测量 VCC 是否明显下降。

### 6.6 一直加热 / 无法关闭

**立即断开 220V**，再排查：

- SSR 输出侧短路或 SSR 击穿（常见失效模式是常通）；
- SSR 选成了常闭型或输出型不匹配；
- D5–D9 在复位/上电时是否被其他电路拉高；
- 输出负载是否接错，导致 SSR 被旁路；
- 板子 GPIO 是否损坏（断开 SSR 输入后测 D 脚电压）。

固件在 `setup()` 中先把所有 SSR 引脚置低，正常上电不应立即加热。如果一上电就加热，
优先怀疑 SSR 或输出侧接线，而不是软件。

### 6.7 恒温震荡 / 通断频繁

- 回差太小：适当增大 `HY`，例如从 0.8 调到 1.0–2.0；
- 探头离加热器太近，测到的是局部热风而不是柜内平均温度；
- 加热器功率相对柜体过大，热惯性小；
- 控制周期 1 秒对快速加热器偏慢，可减小 `CONTROL_INTERVAL_MS`，但会增加 SSR 动作频率；
- 加热器功率不足或柜体散热太大，则会长时间加热仍达不到设定值。

先调回差和探头位置，再考虑改控制周期。频繁通断会缩短 SSR 寿命，阻性负载优先用过零型 SSR。

### 6.8 OLED 黑屏 / 显示异常

- 30 秒无操作会自动息屏，旋转编码器或按一下按键即可唤醒；
- 检查 OLED VCC 是否为 5V、GND 是否共地；
- SDA 必须接 A4、SCL 必须接 A5，不能接反；
- 地址通常是 `0x3C`，少数模块是 `0x3D`；SH1106 不是 SSD1306，需要换 U8g2 构造函数；
- 模块没有上拉电阻时，SDA/SCL 各加 4.7kΩ 到 5V；
- I2C 线太长会导致花屏/黑屏，缩短到 10–20cm 以内优先；
- 串口仍在输出说明主程序在跑，问题集中在显示侧。

可以用下面的 I2C 扫描程序单独排查（临时烧录，扫完再烧回主程序）：

```cpp
#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  for (uint8_t addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.print(F("I2C found 0x"));
      Serial.println(addr, HEX);
    }
  }
}

void loop() {}
```

扫描到 `0x3C` 说明地址和接线基本正确；完全扫不到则查供电、GND、SDA/SCL 和上拉。

### 6.9 编码器反向 / 跳档 / 自己变化

- 反向：交换 A/B 两根线，或对调 D2/D3；
- 转一格跳两档：一格产生了更多正交计数，把 `ENC_COUNTS_PER_STEP` 从 4 增大到 8；
- 转几格才动一档：把 `ENC_COUNTS_PER_STEP` 减小到 2 或 1，同时检查编码器是否接触不良；
- 不动：确认公共脚接 GND、A/B 接 D2/D3、使用内部上拉；
- 自己变化/屏幕不睡：A/B 线受干扰或悬空，加 100nF 到 GND、使用双绞线/屏蔽线，
  并确认没有把编码器公共脚接到 VCC。

按键：SW 接 D4，另一端接 GND；按下为低。短按切换编辑项，长按 800ms 返回运行界面。

### 6.10 设定值不保存

固件只在**退出编辑模式**时写 EEPROM：

- 长按 ≥800ms；
- 编辑中 10 秒无操作自动退出；
- 短按循环回到运行界面。

如果还在 `[SET ...]` 或 `[HY ...]` 编辑状态就断电，修改不会保存。保存格式为
地址 0、魔数 `0x5443`、版本 1、CRC8 校验；校验失败会回退默认 32.0℃ / 0.8℃。

如果每次上电都恢复默认值：

- 确认是否正常退出编辑模式；
- 检查 5V 在写入瞬间是否掉电；
- 可能 EEPROM 数据损坏或固件版本变化，按下面方法擦除后重试。

擦除 EEPROM（会丢失所有设定值）：

```cpp
#include <EEPROM.h>

void setup() {
  for (int i = 0; i < EEPROM.length(); i++) {
    EEPROM.update(i, 0xFF);
  }
}

void loop() {}
```

烧录后等待几秒，再烧回主固件；首次上电会写入默认值 32.0℃ / 0.8℃。

### 6.11 串口乱码 / 没输出

- 波特率必须是 **9600 8N1**；
- 确认烧录时选的是 **5V/16MHz**，不是 8MHz；
- USB-TTL 必须是 5V 电平，TX/RX 交叉并共地；
- 串口监视器不要和上传同时占用端口；
- 没有输出但 OLED 正常：检查 TXO 是否接到 USB-TTL RXD；
- 加热器启动时板子复位/串口断开：电源跌落或强电干扰，改用独立 5V 电源、加储能电容、
  强弱电分离，必要时加光耦/隔离。

## 7. 传感器与整机验证

### 两点/三点温度核对

1. 冰水混合物：碎冰加少量水，搅拌，探头浸入并等待 3–5 分钟，参考 0℃。
2. 稳定室温：用已校准温度计对比，记录每路读数。
3. 温水约 40℃：搅拌，探头防水，等待稳定后对比。

防水探头不要直接浸入强酸碱或长期沸腾的水；用塑料袋/保护套可减少污染。
B3950 + 1% 电阻在 25℃ 附近的一致性好于 ±0.5℃，全量程可能更大，具体取决于探头公差和参考温度计。
若误差是固定偏移，优先核对 NTC 的 B 值/25℃ 阻值；固件没有每通道偏移校准项。

### 带载老化

- 先用灯泡/假负载验证 SSR 通断，再接真实加热器；
- 记录至少 24 小时串口日志，检查是否有 `ERR`、温度是否围绕设定值稳定、SSR 动作是否过于频繁；
- 检查端子、线材和 SSR 散热片温度，不能有变色、焦味或异常发烫；
- 柜体应使用阻燃材料，保留通风和独立超温保护。

## 8. 关键参数速查
